# Files copied VERBATIM from upstream (flash-oss/medici) — byte-identical to the
# pinned SHA (upstream/PINNED_SHA). This is the non-negotiable contract of the
# port: upstream src/ business logic is copied, not rewritten.
#
# A line is an exact path or a directory prefix ending in "/".
# The drift monitor (`npm run upstream:check`, class B) diffs our copies against
# upstream at the new ref. Upstream-only movement while our copy still matches
# the pin is a "clean fast-forward" (informational); anything else is drift.
#
# When bumping the pin: re-copy with `npm run upstream:baseline <sha>` and
# commit the re-copied files together with the matrix + provenance + surface.
#
# Pin integrity is PERMANENT (M17): upstream/SRC_PROVENANCE.md stores the
# expected sha256 of every file listed here, and `npm run lint`
# (upstream-check class E, --pin-only) plus CI fail on any mismatch. Editing
# a verbatim file breaks the build until the table is regenerated with
# `npm run upstream:baseline <sha>`.
#
# Documented deviations (NOT byte-identical to the pin):
#   src/errors/index.ts — adds the UnsupportedMongoOperationError export
#     (the one permitted addition to errors/, ITD-94). Its table row stores
#     the ported hash (marked "(ported)") and `upstream:baseline` re-applies
#     the export after every re-copy.
